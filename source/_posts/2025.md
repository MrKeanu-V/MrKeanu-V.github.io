# 2025

## 编程

25年编程主要集中在了深度学习实验和实习。

#### 深入AI

因为被延毕，所以得以更“奋不顾身”地投入AI，学习理论并进行实验。期间实现了一个个人的相对通用的CV实验框架，复现了一些未开源的Metrics和Ideas。框架的整个实现真正地使我理解深度学习，而非浮于论文，浮于理论。反反复复的实验中我发现了太多太多细节的问题，而这些细节往往不是那些论文中会提及到，相反却是尤为致命的，一点差异可以让指标异常虚高，让论文"漂亮"，但那并不真实。这期间对AI尤其是CV相关的诸如CV底层原理和实验细节，如数据处理、网络模型复现、Metrics实现和对齐等等都有了非常深刻的理解，同时更加对科研祛魅。回想起某夜的凌晨四点，自己修补完的实验框架，解决完一个个bug时，看着整个项目代码，数十个模型实现，好像透过它们看到了AI本质（我记录一些笔记和思考，后续会全部更新在博客中）。那种豁然开朗的感觉，宇宙在我脑海中展开浩瀚，很像经典meme——我逐渐理解了一切.jpg。“朝闻道，夕死足矣”不是空谈，这种厚积薄发、积思顿悟的时刻，希望不绝于此。

#### C++实习

实习阶段第一次接触如此庞大甚至古老的项目，源码来自SDRC公司的IDEAS，整个仓库超过3000万行代码。脚本history里甚至能看到1982年的记录，其实我还在注释里发现了老一辈程序员留下的一些小彩蛋，这感触比看到那些古董代码更令我惊喜和印象深刻🤣。完全不同于学校里打得那些“黑工”，实习的收获巨大。这种收获不仅是在C++特性、CMake、Debug等开发内功的夯实上，对于软件工程、团队协作（尤其是同一个项目如何AI工具层面的协作）、质量保证等工程化方面也有了更深的理解。关于这些方面个人的思悟理解我会分享在单独的篇章中，便不在年度总结中赘述。



{% note warning %}

25年在编程方面最大的感受是：**优质数据集不仅对AI很重要，对人类也很重要**。

{% endnote %}

这种差别就像是分别用武林秘籍和第八套广播体操来练功一样，同样资质下那肯定是修习武林秘籍的人武力值更高。这一点在我学习硬件时就有发现，在实习后感触更深。学习STM32时，由于开发板和生产厂商高度绑定，所以厂家一般会提供专门的高质量的学习资料教你如何配置工具和开发Demo（如点亮流水灯，入门第一步了属于是🙈）。而学习软件则大不相同（至少在AI发展之前），学习软件最大的难点就是找到合适的教材和教程。教材上大多不直观和过时，而软件开发尤其是初学者而言，直观和时效非常重要。至于教程更是槽点太多，网络上充斥着良莠不齐、滥竽充数的视频。半碗水的培训班大行于世可谓是严重污染了“语料库”，一个浅显的功能或API要大水一两个小时，实在难以忍受🫠。而实习的最大帮助就是提供了一个质量有保障的“数据集”，最直观的就是有足够多现成的最佳实践供我在学习并实践。相反在学校里的大部分情况下，我就是负责人，整个项目的品味和”高度“也都受限于我，也正因此存在巨大的盲区。外加彼时AI也不算发达和容易获取，各种经验性的问题都需要自己花很多时间去填”兔子洞“，同时也看不到”天花板“，即使知道这种实现不合适也不知如何Improvement。这好比一道算法题AC了60%，不仅不知如何优化，甚至连那40%都看不见。

{% note success %}

这个感受归纳并延伸，其实就是**不要做房间里最聪明的人**——如果你是这个房间最聪明的人，那说明你走错房间了。

{% endnote %}



## 阅读

25年因个人原因读书较少，算上电子书有：《毛泽东自述》、《思考快与慢》、《小岛经济学》、《沧浪之水》、《蛤蟆先生去看心理医生》、《Effective Morden C++》、《我不是废柴》、《美国反对美国》。最受益的书有两本：《沧浪之水》、《美国反对美国》，技术类的有一本：《Effective Morden C++》。

其中《蛤蟆先生》和《小岛》都类似趣味小短篇，算作科普类读物。前者是心理咨询师推荐的，后者是一位热爱读书的朋友推荐。《我不是废柴》则是别人推荐了《凡人歌》，无时间和兴趣看剧不得已读原书，但本书实在是烂俗到无可忍受，遂弃之。{% label info @"我Chovy，安利给我安利好的呀".jpg %}😅。



#### 《毛泽东自述》

本书当算是“温故知新”，大部分章节我都已在《毛泽东青年传》和《毛选》中读过。没什么读后感好再摆弄的，只有{% label danger @“实事求是，活的灵魂“ %}！

#### 《思考快与慢》

此书来自学经济的朋友力荐，从去年读到今年，时断时续。主要还是因为书实在太厚了，而且"学术感"十足（尽管很多例子十分生硬，而且缺乏学术地考究，我现在都仍记得作者对女性和他国的狭隘偏见）。数十页的内容仅是讲一个"简明"的观点，严谨的词藻导致的严重的"翻译腔"。32万余字的《快与慢》，使得书捧起来吃力，读起来乏味，阅读也就成了"快与慢"。尽管书中很多观点令我受益匪浅，越读到后面越是值得深思，但我还是认为它若是浓缩一半，我会把它推荐给所有人。但作者用32万字来补充和陈述，那我更建议大家"浅尝辄止"，不妨仅读每章第一节，有雅兴or不解时再品味全文。

#### 《蛤蟆先生去看心理医生》

《蛤蟆先生》是一本读完让人觉得温暖的心理学科普读物。读后感是，生活很简单，幸福也不难；管理和调整个人观察世界的视角，接纳与善待个人的所有情绪。不知为何，写到这里会想起木心，他的一篇散文[^1]里提到，{% label primary @ "人不是容器，人是导管，悲伤流过，快乐流过，但导管还是导管" %}。 

#### 《小岛经济学》

《小岛》作为一个科普类读物，所谈的经济现象和原理早已是滚瓜烂熟，不过我喜欢作者亮出其经济观点时的直言不讳。虽说不尽苟同，至少仍比那些厚重的经济学著作里晦涩且面面俱的文字倒是来得痛快一些，那些教材书籍里摆明观点时宛如在写"免责声明"。

#### 《沧浪之水》

{% note info %}

"沧浪之水清兮，可以濯吾缨。沧浪之水浊兮，可以濯吾足"。 —— 《沧浪歌》

{% endnote %}

该书是我25年读过思悟最深的书。仅从剧情来讲本书确存爽文套路嫌疑，但主旨不俗内蕴不浅，作者欲探讨的内核切中我长久思索的课题之一。故事的主人翁池大为是对我，对我这样的人一面镜子，也是一记强有力的棒槌。作者笔下主角成长历程一定程度倒影出我的来时路，连同那些多思、焦虑、失眠、拧巴、痛苦与心中那淤堵黏滞且难以向任何人告解的怒火。但我始终不是池大为，也不是丁小槐。谁也不是，谁也不可能是。若把自己完全比作二者，那不过是妄自尊大同时又妄自菲薄罢了。 一方面，诚然求学路上读的都是圣贤书，但就像《1566》里编剧借胡宗献之口所言——"圣人书拿来做事一无是处"。 文中关于"大小自由"之辩饶有趣味。人要有志向更要有气节，但不是自命不凡清高排外。要向学习王守仁的"内抱不群，外欲混迹"。要脱下夫子长衫，用尽手段争取成事。但在实践中切不可泯灭个人追求和原则，外圆内方。不忘初心，知之可为与不可为。我需要更多的朋友或者对手，一段旅程的同路人也可，志同道合者那更好。 因此社会的课堂里，我要学的还很多，很多。成长的过程就是该千刀万剐，挫骨敲髓！好在我不觉气馁，更不感挫败。**走在深谷里使我恐惧的同时也让我兴奋，好似期待着尼采提及的那道令人震颤的闪电……** 另一方面，这不应是且就不是一本"厚黑学"的教材，那才是一种处心钻营的浅薄。作者用池大为、丁小槐等角色塑造起一面面镜子，并在镜子背后藏有一壑深渊。众人只照见镜子就开始对号入座口诛笔伐，却选择对深渊避而不见。人民物质生活确实比过去富足，即使人性亘古不变；百姓精神观念确实在历朝历代中进步，纵使人性亘古不变；人类社会在历史长河里螺旋上升，哪怕人性亘古不变。 看见清高与坚守就大批迂腐，你我鱼肉却还嘲弄起公平和正义。这堪比大棒还没砸到身上就开始自断胫骨，委屈求全。这种观念如同驯化，方才是藏在此书之下的一汪渊壑，也是一切不公平的根源。写到最后，不禁回味本书题记《沧浪歌》，"沧浪之水清兮，可以濯吾缨。沧浪之水浊兮，可以濯吾足"。荡气回肠，与君共勉~

#### 《美国反对美国》

本书为作者在1988年访学美国两周，将之见闻分析成书。阅读此书那是常常对作者登峰造极的观察力叹为观止！彼时美国是如日中天、不可以物，已然是全世界尤其是“公知”们的文明灯塔。在这样的大背景下，作者观点犀利宛如利剑，严肃但不失客观地分析了美国的优点以及问题。在我心中，这本书已是一本社会学精品，尽管它没有社会学著作那样严谨的实验。读完后依旧回味不止，惊异于作者的世事洞明，也庆幸作者如今走向了更大的舞台🫡。

#### 《Effective Morden C++》

本书不能算作一本正经的"技术书籍"，更像是一本C++的"最佳实践"。它不过分细究技术实现，也不过分讨论背景与发展。它就是作者在几十年的C++开发总结而成的经验，归纳为24条准则，涵盖类的定义、左值右值、范型编程、多态、多线程等各种细枝末节。正是这本书，帮助我理解了C++范型、元编程的原理，以及深入理解了C++最容易忽略、却最容易引起问题的左值和右值。坦诚讲，这本书不长，而且我现在认为它在深度上也有所欠缺，尽管要看懂它仍需要一些C++经验。如果你想迅速进阶C++开发功力，我非常建议你读读此书，它作为"抛砖引玉"的引子再合适不过。



## 最有意义的事

写年度总结往往并不在年末，今年就拖到了来年报春花开，何况"笔耕常辍"。要给2025年回忆一件最有意义的事，我坦言有些发懵。这一年经历了太多，黑暗和痛苦，回忆这些刺痛的日子，仍然让我略微不适。但痛定思痛，人总得向前看，黑暗中更是如此。

#### 那拉提

![Ride Or Die](/image/ride_or_die.jpg)

{% note success %}

我心中的草原更辽阔，马也更骏烈

{% endnote %}

上半年爱人的毕业旅行捎带上了我，说是也带我去散心。二十多小时的硬座远赴伊犁，好在一路的风景外加新鲜感是我们不觉太累。新疆给我的印象是空气干燥，城市与城市相隔遥远。很久没见到那样高远干净的天空，山很遥远碧空无穷，道路一直蔓延到视野尽头。比起山城的酷热和起伏，这里的一切确实显得祥和。牛羊和马儿慢悠悠在公路上，对路过的人和滴喇叭的车置若罔闻。在那拉提草原上，我第一次骑马。骑马这行为本身的体验很好，挥鞭在草原上来回奔跑，很危险，也很痛快。但骑马这件事让我有很多思考……景区里的大大小小多个马队，马队的马来自附近的牧民。马队里的马看起来都有些疲惫，可能由于频繁待客的缘故，和旅客的神彩对比鲜明。骑马和开车不同，马总是不听使唤，你必须拉紧缰绳，使劲抽鞭它才会跑起来，而且跑不了几步。这可能因为牧民一般也只舍得用品相较次年龄稍大的马加入马队。马跑起来时的喘息声其实非常大，如果不拉紧缰绳它就跑到树荫处，慢走时不留意它又会驻足埋头吃草。这让我意识到，马是一种动物，想偷懒想休息，像人一样。要把动物变成工具使用它奴役它，就必须“强权”，而强权隐含着强迫。{% lable danger @这让我有些难过，这一点上人和马又有什么区别呢？ %}我在草原上追逐风、呼喊着自由，自由两字里却条条框框尽是不自由，马不自由，我也不自由。是啊，世界在生存的角度上显然是残酷的、血腥的，“勇敢的人先享受世界”无疑成了一块遮羞布，享受世界的人往往不是因为勇敢，而是因为拥有享受的条件。所谓条件本质就是“资源”，那资源从哪里来？有产者靠剥削，无产者靠出卖。如果别无选择，希望我能找到自己的“勇敢”，尔后再争为这世界做一点什么，哪怕丁点也好。

#### 一碗排骨汤

![一碗简单的排骨汤](/image/simple_rib_soup.jpg)

{% note success %}

“贤妻扶我青云志，我还贤妻万两金“

{% endnote %}

爱人照顾我的岁月，为我做了一份排骨汤，朴素的食材不加任何多余的料理，却香到堪称沁人心脾。现在想起来，可能是爱浸溢出来了。打下这段字，眼睛都有些湿润。那段日子爱人刚工作，而我闲置在家，巨大的打击使我破碎不堪，靠药物维持，终日浑噩。小小的房间没有专门的厨房，爱人在厕所用一个电锅，将社区团购的食材烹制。炒菜的油烟模糊了厕所的玻璃门，雾蒙蒙的，看不清起雾的是玻璃还是我的眼睛。早年听过一句古龙的名言，尽管我并不曾读过几本武侠，他说{% label danger @"一个人如果走投无路，心一窄想寻短见，就放他去菜市场吧" %}[^2]。从那一刻起，我开始相信他说得对。

这件事令我记忆深刻，体悟颇深。高中时榆木，书中看过太多爱情故事，分分合合。这使我不得不追问什么样的感情才稳定？”激情演变成陪伴，陪伴生长出亲情。“——这是我当时的答案。如今我会再加一条，恩情。夫妻有恩，不离不弃，共难共福。

另一方面，之于自己，人不是生下来就成功的，就豁然于事理，立足于世界。释迦摩尼、耶稣、韩信……数不清的英雄名人在籍籍无名之时皆独拣寒枝，靠人供养。正如此，爱人是我的第一位天使投资人，哪怕仅为这一碗汤，我也不会再想”放弃自己“——只因我理应报答。

## 思悟

{% note success %}

There is a Crack in Everything, That's How the Light Gets in. —— [Leonard Cohen](https://en.wikipedia.org/wiki/Leonard_Cohen) 《Anthem》

{% endnote %}

人生里程碑，一次彻底的失败，卑若微尘。**失败也是重要的人生体验**，事实上，我本也不乏失败，一路走来都是坚持和侥幸。

最后一次登陆教务系统，凌晨三四点，验证码恰好是**9981**，九九八一啊。你说世间怎么就那么多恰好？我发现了的恰好，还未发现的恰好……

失眠和焦虑几乎摧垮了我，那段时间躺在床上，合上眼，心脏就开始砰砰直跳，一宿无眠。或许是谁把我的梦，偷走了。心率不齐，憔悴不堪。挨到天亮，一股血腥味从喉咙里蔓延而出。胸口钝痛，手臂发麻，我感到害怕，从没有那么一刻，感觉自己如此接近死亡。嘴里的血腥味不合时宜的有些甜，淡淡的甜，甜得有些妖冶，像是在向我挥手，招呼”过去“吧。那段时间里，每个夜晚都是一场无声的残斗，实际我每次都失败了，每一次我都选择放弃，就这样死去倒也是解脱。可次日，我还是活着，折磨还在继续……

如今已不再服用抗焦虑、抗抑郁的药物，但那段日子回想起来还是混沌。整个人好像内部发腐，皮肉下有一道看不见的裂痕，每个晚上都在源源不断得向外流失，流失生命力、流失希望、流失勇气……

![Sunrise Sayram Lake](/image/sunrise_at_sayram.jpg)

好在一切都过去了，都过去了，或许是这样。万物都有裂痕，那是光照进来的地方！

**我是说，无人问津乃是常事，深谷里看不见前路才是难挨。连月光都没有都黑夜里，跪俯地面一粒粒捡拾自己灵魂的碎片。算了，来路泥泞，曲折辛酸，不提也罢。 命运加之性格给我铺织一条崎岖的道路，在我高昂胸脯时轻喃悲歌，在我勇敢迈步时暗诉哀怨。年轻的我勇往前迈，不知宿命悄悄跟随。我的失意和疲惫滋养这它，直到某天攀附上肩头，再如蟒蛇将我绊倒紧紧缠绕。如果就此没机会探探山的后面。那我便自嘲，不过仍是山而已。是谓，正入万山圈子里，一山放过一山拦。** 

失败也是重要的人生体验，一个人不仅要知道为什么赢，更需要知道为何而输。若自比作AI，那天性与天赋就是模型的基础能力，也可以说是基本参数量，所有的经历就是训练所用数据集，那失败就是数据集中的反例，更需要针对性的学习～。
